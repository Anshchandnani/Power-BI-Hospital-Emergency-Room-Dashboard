# Hospital Emergency Room Dashboard \| Power BI

## Overview

This is my fourth Power BI dashboard project: a Hospital Emergency Room
Dashboard built using a provided hospital ER dataset. I followed a
YouTube tutorial as a learning reference and practised connecting
tables, managing table relationships, transforming data, and creating a
dedicated date table.

The report contains four pages: Monthly View, Consolidated View, Patient
Details, and Key Takeaways.

## Dashboard Pages

### 1. Monthly View

Provides a month-level view of emergency room activity, including
patient volume, average wait time, patient satisfaction, referrals,
admission status, age groups, gender, race, department referrals, and
patient volume by day and hour.

### 2. Consolidated View

Summarizes the same core metrics across a selectable date range to
support a broader view of emergency room performance.

### 3. Patient Details

Displays patient-level fields such as patient ID, name, gender, age,
admission date, race, wait time, department referral, and admission
status.

### 4. Key Takeaways

Presents a written descriptive analysis of the dashboard metrics and
highlights patterns that may help stakeholders explore emergency room
operations.

## Skills Practised

-   Connecting data sources in Power BI
-   Transforming and cleaning data using Power Query
-   Managing tables and relationships in the data model
-   Creating a dedicated date table for date-based analysis
-   Designing a multi-page report
-   Creating KPI cards, trend charts, bar charts, donut charts, and a
    day-and-hour heatmap
-   Building date-based views and report navigation
-   Presenting findings through a key-takeaways page

## Key Metrics Displayed

-   Number of patients
-   Average wait time
-   Patient satisfaction score
-   Number of patients referred
-   Admission status
-   Percentage of patients seen within 30 minutes
-   Patient demographics
-   Patient volume by day and hour

## How to Open

1.  Download or clone this repository.
2.  Open the `.pbix` file in Microsoft Power BI Desktop.
3.  If Power BI requests the source file, update the data source path to
    the included CSV file.
4.  Explore the four report pages and interact with the available
    filters.
